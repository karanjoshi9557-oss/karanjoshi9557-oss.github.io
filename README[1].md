# Karan Joshi Portfolio

GitHub Pages-ready static portfolio based on the current Hatchable portfolio.

## Files
- `index.html` — main portfolio
- `resume.html` — printable resume
- `assets/karan.jpeg` — profile photo
- `.nojekyll` — keeps GitHub Pages from applying Jekyll processing

## GitHub Pages
For a GitHub Free account, use a **public repository**. A repository named
`karanjoshi9557-oss.github.io` will publish at:

https://karanjoshi9557-oss.github.io/

In the repository: **Settings → Pages → Build and deployment → Source → Deploy from a branch → main → /(root) → Save**.
